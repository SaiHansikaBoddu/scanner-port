Network Security Fundamentals: How Port Scanning Works

1. TCP 3-Way Handshake

The scanner initiates connection via SYN packet. If a service is listening, the target responds with SYN-ACK. If closed, it returns an RST (Reset) packet.

2. Python socket.connect_ex()

The backend uses s.connect_ex((ip, port)). A return code of 0 indicates a successful connection (OPEN), while non-zero signals connection refused (CLOSED).

3. Service Identification

Well-known port numbers (such as Port 80 for HTTP, 443 for HTTPS, and 22 for SSH) map to standardized network protocols defined by IANA.
